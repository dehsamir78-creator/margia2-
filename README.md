# Margia

Simulateur de bénéfice net par vente pour e-commerçants et dropshippers en micro-entreprise (France).

Site statique : déployé sur Vercel depuis la branche `main`.

## Base de données (Supabase > SQL Editor, dans l'ordre)
1. `supabase/schema.sql`
2. `supabase/002_billing.sql`
3. `supabase/003_declarations.sql` (historique des déclarations URSSAF)
